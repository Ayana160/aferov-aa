# HelpDesk — информационная система обработки заявок

WPF-приложение на C# / .NET для учебной практики.

## Структура

- Views — окна (LoginWindow, MainWindow, TicketCreateWindow, TicketEditWindow)
- Models — модели данных (User, Ticket, Category, Status, Priority)
- Data — работа с БД (пока заготовка)
- Services — сервисы (AuthService)
- Helpers — вспомогательные классы
- База_данных — SQL-скрипт создания БД

## Запуск

1. Откройте HelpDesk.csproj в Visual Studio.
2. Нажмите F5.
3. Логин: admin
4. Пароль: 12345

## Что реализовано

- Окно авторизации с проверкой пустых полей и временной авторизацией
- Главное окно со списком тестовых заявок (DataGrid)
- Поиск по описанию, категории, статусу
- Фильтрация по статусу
- Совместная работа поиска и фильтра
- Создание и редактирование заявок (интерфейс)
- Подтверждение удаления
- Выход из системы
- Единые стили кнопок
- Отображение количества заявок и текущей даты

## База данных

SQL-скрипт: База_данных/HelpDesk_Student.sql

Создаёт базу HelpDesk_Student с таблицами Roles, Categories, Priorities, Statuses, Users, Tickets и тестовыми данными.

Подключение к БД будет реализовано в следующих практических работах.
